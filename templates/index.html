Background

Research Overview

This project investigates the effectiveness of supervised machine learning algorithms in detecting and classifying network intrusions using the NSL-KDD benchmark dataset.

dataset

NSL-KDD Dataset

An improved version of the KDD Cup 1999 dataset, eliminating duplicate records and redundant instances. Used as the standard benchmark for IDS research worldwide.

model_training

Three ML Classifiers

Random Forest, Decision Tree, and Support Vector Machine (SVM) classifiers were trained, evaluated, and compared for intrusion detection performance.

tune

Feature Engineering

20 optimal network traffic features were selected from 41 raw attributes using feature importance analysis to improve model efficiency and accuracy.

account_balance

Academic Institution

Conducted at the Tai Solarin Federal University of Education (TASFUED), Department of Computer Science, under the supervision of Mrs. Ogunbanjo.

Classification

Attack Categories Detected

The system classifies network traffic into five distinct categories based on NSL-KDD labels.

NORMAL

Normal Traffic

Legitimate network connections with no malicious intent or abnormal behaviour patterns.

DoS

Denial of Service

Attacks that flood network resources, making services unavailable to legitimate users. e.g. SYN flood, ping-of-death.

Probe

Probing / Scanning

Surveillance attacks that gather information about the network to identify vulnerabilities for future exploitation.

R2L

Remote-to-Local

Unauthorised remote access attacks where an intruder exploits vulnerabilities to gain local account access.

U2R

User-to-Root

Privilege escalation attacks where a local user illegitimately gains root or superuser system privileges.

Pipeline

System Methodology

The IDS follows a structured ML pipeline from raw network data through to real-time classification and alerting.

01
storage

Data Collection

Network traffic records from the NSL-KDD benchmark dataset (KDDTrain+ / KDDTest+) covering normal and attack connections across 41 raw features.

02
transform

Preprocessing

Categorical features (protocol_type, service, flag) are label-encoded. Numerical features are standardised using StandardScaler to normalise value ranges.

03
filter_alt

Feature Selection

20 most discriminative features are selected from 41 using Random Forest feature importance scores, reducing dimensionality and improving inference speed.

04
model_training

Model Training

Three classifiers — Random Forest, Decision Tree, and SVM — are trained on the processed dataset. SMOTE oversampling addresses class imbalance in minority attack types.

05
bolt

Real-Time Inference

Incoming network traffic is preprocessed and classified in real time. Detected attacks are immediately logged and security alerts are raised in the dashboard.

Evaluation

Model Performance Results

All three classifiers were evaluated on the KDDTest+ holdout set. Results show model accuracy and F1-score across all five traffic classes.
